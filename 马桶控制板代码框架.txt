一、硬件资源映射
================================================================================

1. 强电控制 (低电平有效，通过 MOC3023 驱动可控硅)
   ├─ PA0: 过零信号输入 (连接 LTV-814S 光耦输出)
   ├─ PA1: 风扇加热丝 (支持移相调压)
   ├─ PA2: 水泵
   ├─ PA3: 水即热装置 (支持移相调压)
   └─ PA4: 粉碎泵

2. 步进电机控制 (通过 74HC595 + ULN2803)
   ├─ PA5: 595 Data (SER)
   ├─ PA6: 595 Latch (RCLK)
   ├─ PA7: 595 Clock (SRCLK)
   ├─ 电机1: 595输出低4位 (Q0-Q3)
   └─ 电机2: 595输出高4位 (Q4-Q7)

3. RS485 通信
   ├─ PA8: 控制脚 (DE/RE)
   └─ PA9/PA10: Serial1 (TX/RX)

4. 继电器控制
   ├─ PB8:  烘干风扇
   ├─ PB9:  除臭风扇
   ├─ PB10: 电磁阀1
   ├─ PB11: 电磁阀2
   └─ PB12: 电磁阀3

5. 温度传感器
   └─ PB0: NTC温度传感器 (ADC输入)


二、核心技术原理
================================================================================

1. 过零检测开关技术
   ├─ 原理: 交流电过零点切换强电负载，减少电磁干扰
   ├─ 触发频率: 50Hz (每10ms触发一次)
   ├─ 中断函数: zeroCrossingISR()
   └─ 应用: 水泵、粉碎泵的开关控制

2. 移相调压控制技术
   ├─ 原理: 延时触发可控硅，控制导通角实现功率调节
   ├─ 定时器: TIMER2(水即热) / TIMER3(风扇加热丝)
   ├─ 功率档位: 20%, 40%, 60%, 80%, 100%
   └─ 延时计算:
       - 20%功率: 延时8ms，导通2ms
       - 40%功率: 延时6ms，导通4ms
       - 60%功率: 延时4ms，导通6ms
       - 80%功率: 延时2ms，导通8ms
       - 100%功率: 延时100μs，几乎全导通

3. 非阻塞步进电机控制
   ├─ 驱动方式: 双相励磁 (扭矩大)
   ├─ 相位序列: 0x0C → 0x06 → 0x03 → 0x09 (正转)
   ├─ 相位序列: 0x09 → 0x03 → 0x06 → 0x0C (反转)
   ├─ 步进参数: 300步/圈，5ms/步
   └─ 状态机: 支持多阶段复合动作


三、全局变量分类
================================================================================

1. 强电负载控制变量 (volatile，中断中使用)
   ├─ targetStatePump: 水泵目标状态
   ├─ targetStateMacerator: 粉碎泵目标状态
   ├─ fanDelayMicros: 风扇加热丝延时时间(微秒)
   ├─ fanTriggerEnabled: 风扇加热丝使能标志
   ├─ heaterDelayMicros: 水即热延时时间(微秒)
   └─ heaterTriggerEnabled: 水即热使能标志

2. 温度监控变量
   ├─ currentTemperature: 当前温度值
   ├─ lastTempTime: 上次温度更新时间
   └─ lastUploadTime: 上次温度上传时间

3. 步进电机运行参数
   电机1:
   ├─ motor1Running: 运行标志
   ├─ motor1StepPhase: 当前相位 (0-3)
   ├─ motor1StepCycle: 当前步数计数
   ├─ motor1TargetSteps: 目标总步数
   ├─ motor1Direction: 方向 (true=正转)
   ├─ motor1Enabled: 使能标志
   └─ motor1RevolutionCount: 圈数计数

   电机2: (同上)

4. 复合动作状态机
   ├─ command1Status: cmdAction1 状态标志
   ├─ command2Status: cmdAction2 状态标志
   └─ command3Status: cmdAction3 状态标志

5. 74HC595 输出缓存
   ├─ currentShiftOutput: 当前输出字节
   ├─ motor1Nibble: 电机1的4位状态
   └─ motor2Nibble: 电机2的4位状态


四、指令集定义 (RS485通信协议)
================================================================================

指令格式: [0xEE][0x01][0x00][参数1][0x00][参数2][参数3][参数4]

1. 步进电机指令
   ├─ motor1FwdCmd: 电机1正转
   ├─ motor1RevCmd: 电机1反转
   ├─ motor2FwdCmd: 电机2正转
   ├─ motor2RevCmd: 电机2反转
   ├─ cmdAction1: 复合动作1 (M1逆+M2正)
   ├─ cmdAction2: 复合动作2 (全逆转)
   └─ cmdAction3: 复合动作3 (多阶段动作)

2. 强电负载指令
   ├─ cmdFanOn/Off: 风扇加热丝开关
   ├─ cmdPumpOn/Off: 水泵开关
   ├─ cmdMacOn/Off: 粉碎泵开关
   ├─ cmdDryFanOn/Off: 烘干风扇开关
   ├─ cmdDeodorFanOn/Off: 除臭风扇开关
   ├─ cmdValve1On/Off: 电磁阀1开关
   ├─ cmdValve2On/Off: 电磁阀2开关
   └─ cmdValve3On/Off: 电磁阀3开关

3. 水即热功率控制指令
   ├─ cmdHeatOff_New: 关闭
   ├─ cmdHeat20: 20%功率
   ├─ cmdHeat40: 40%功率
   ├─ cmdHeat60: 60%功率
   ├─ cmdHeat80: 80%功率
   └─ cmdHeat100: 100%功率

4. 温度数据上传
   格式: [0xEE][0x10][0x00][0x01][0x00][0x01][温度高字节][温度低字节]
   说明: 温度值×10转为int16_t补码形式


五、核心函数架构
================================================================================

1. 初始化函数 (setup)
   ├─ 串口初始化 (Serial, Serial1)
   ├─ GPIO引脚配置
   ├─ 定时器配置 (TIMER2, TIMER3)
   ├─ 过零检测中断配置
   ├─ ADC初始化
   └─ 步进电机归零

2. 主循环函数 (loop)
   ├─ handleStepperMotor(): 步进电机非阻塞控制
   ├─ handleRS485Commands(): RS485指令接收处理
   ├─ readTemperature(): 温度读取 (每2秒)
   └─ uploadTemperatureData(): 温度上传 (每5秒)

3. 中断服务函数
   ├─ zeroCrossingISR(): 过零检测中断
   │   ├─ 处理风扇加热丝移相调压
   │   ├─ 处理水即热移相调压
   │   └─ 处理水泵、粉碎泵开关
   ├─ heaterTimerCallback(): 水即热定时器回调
   └─ fanTimerCallback(): 风扇加热丝定时器回调

4. RS485通信函数
   ├─ handleRS485Commands(): 接收并解析指令
   ├─ processHexCommand(): 指令处理分发
   └─ sendHex485(): 发送应答数据

5. 步进电机控制函数
   ├─ handleStepperMotor(): 主控制逻辑
   ├─ startMotor1/2(): 启动电机
   ├─ stopMotor1/2(): 停止电机
   ├─ calculatePhaseMotor1/2(): 计算励磁相位
   ├─ finishRevolutionMotor1/2(): 完成一圈后的处理
   └─ updateShiftRegister(): 更新74HC595输出

6. 温度监控函数
   ├─ readTemperature(): 读取NTC温度
   ├─ temperatureToTwoBytes(): 温度值转补码
   └─ uploadTemperatureData(): 上传温度数据


六、程序执行流程
================================================================================

1. 系统启动流程
   setup() 初始化
   ├─ 配置所有GPIO为默认状态
   ├─ 配置定时器 (TIMER2, TIMER3)
   ├─ 开启过零检测中断
   └─ 进入主循环

2. 主循环执行流程
   loop() 循环
   ├─ 检查步进电机状态，执行步进
   ├─ 检查RS485缓冲区，处理指令
   ├─ 每2秒读取温度
   └─ 每5秒上传温度数据

3. 过零中断执行流程 (每10ms触发一次)
   zeroCrossingISR()
   ├─ 检查风扇加热丝状态
   │   └─ 如果启用，启动TIMER3延时触发
   ├─ 检查水即热状态
   │   └─ 如果启用，启动TIMER2延时触发
   ├─ 立即切换水泵状态
   └─ 立即切换粉碎泵状态

4. 指令处理流程
   收到RS485指令
   ├─ 检测帧头 (0xEE)
   ├─ 接收完整8字节
   ├─ processHexCommand() 解析指令
   ├─ 执行对应操作
   └─ 发送应答

5. 复合动作执行流程 (以cmdAction3为例)
   收到cmdAction3指令
   ├─ 阶段1: M1正转1圈 + M2正转1圈
   ├─ M2完成后进入阶段2
   ├─ 阶段2: M2反转0.4圈
   ├─ 两个电机都停止后
   └─ 打开电磁阀3


七、关键技术参数
================================================================================

1. 步进电机参数
   ├─ 步数/圈: 300步
   ├─ 步进速度: 5ms/步
   ├─ 励磁方式: 双相励磁
   └─ 驱动芯片: 74HC595 + ULN2803

2. 温度传感器参数
   ├─ 类型: NTC 10kΩ (25°C)
   ├─ B值: 3950
   ├─ 上拉电阻: 10kΩ
   ├─ ADC分辨率: 12位 (4095)
   └─ 计算方法: Steinhart-Hart方程

3. 通信参数
   ├─ RS485波特率: 9600
   ├─ 数据格式: 8字节十六进制
   ├─ 超时时间: 20ms
   └─ 应答机制: 收到指令后立即应答

4. 定时器参数
   ├─ 时钟源: 72MHz
   ├─ 预分频: 71 (1MHz计数频率)
   ├─ 计数单位: 1微秒
   └─ 延时范围: 100μs ~ 8000μs


八、安全机制
================================================================================

1. 过零检测保护
   └─ 强电负载只在过零点切换，避免浪涌电流

2. 非阻塞设计
   └─ 所有耗时操作均采用状态机，不阻塞主循环

3. 超时保护
   └─ RS485接收带20ms超时机制

4. 状态机互锁
   └─ 复合动作执行期间，新指令会重置状态机

5. 默认安全状态
   └─ 上电时所有强电负载默认关闭


九、扩展接口
================================================================================

1. 可扩展的指令集
   └─ 预留指令空间，可添加新功能

2. 模块化函数设计
   └─ 各功能模块独立，便于维护和扩展

3. 参数可配置
   └─ 步进速度、步数、功率档位等参数可调整
